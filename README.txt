국방예산 웹 대시보드

실행: index.html을 Chrome 또는 Edge에서 열면 됩니다.
인터넷 연결이나 추가 설치 없이 작동합니다.

파일 구성
- index.html: 대시보드 화면
- style.css: 화면 디자인과 반응형 레이아웃
- app.js: 필터, 차트, 정렬, 검색, CSV 다운로드
- data.js: 원본 엑셀 상세 항목 32개의 데이터 스냅샷

사용 방법
1. 부문 및 회계구분을 선택하면 모든 그래프와 지표, 상세 표에 반영됩니다.
2. 차트 위에 마우스를 올리면 상세 금액을 확인할 수 있습니다.
3. 표의 열 제목으로 정렬하고 검색창으로 상세 항목을 검색할 수 있습니다.
4. '선택 데이터 CSV'는 부문·회계구분 필터에 해당하는 전체 상세 데이터를 저장합니다.
5. '원본 엑셀 다운로드'는 폴더에 동봉한 source.xlsx 스냅샷을 다운로드합니다.

데이터 기준
- 출처: ../붙임1_프로그램별_재원.xlsx
- 2027년은 정부안이며 금액 단위는 억 원입니다.
- 상세 항목 32개만 사용하며 합계 행 9개를 제외하여 중복 집계를 방지했습니다.
- 내부거래 차감액을 순재원에 포함하며, 구성비와 예산 맵은 양수 재원만 사용합니다.
- 증감률 = (2027년 - 2026년) / 2026년입니다.
- 상세 항목의 반올림으로 전체 순재원은 원문 총재원 표보다 연도별 1억 원 작습니다.
- 엑셀을 수정해도 자동 반영되지 않습니다. data.js를 갱신해야 합니다.
